# Changelog

## [0.3.1] - 2026-11-01

### Changed
- Compatible with Nextcloud 34 and 35.
- New App Store title, summary and description (Peppol BIS, EN 16931, XRechnung, ZUGFeRD and Factur-X).
- No functional changes.

## [0.3.0] - 2026-10-28
### Added
- Nine screenshots and an updated README for the store listing.
### Changed
- Adjustments are shown as cards on small screens.
### Fixed
- Badge display fix.

## [0.2.0] - 2026-10-08
### Added
- First public release: viewer for UBL and CII invoices (invoice, credit note, corrective invoice, self-billed invoice).
- On-demand EPC/SEPA payment QR code.
- Embedded XML from hybrid PDFs via the menu "UBL/CII Viewer (embedded XML)" (requires `pdfdetach` from Poppler).
